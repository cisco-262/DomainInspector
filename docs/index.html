DOMAIN HEALTH INSPECTOR

Domain Health Inspector — See domain, DNS, and HTTPS health at a glance

Domain Health Inspector brings domain expiry, DNS records, HTTPS reachability, TLS handshakes, and mail security checks into one focused app for personal sites, APIs, home servers, and small team assets.

FEATURES

Checks organized around real domain usage

Instead of giving domains a confusing score, Domain Health Inspector identifies whether checks are normal, need attention, disabled, or not configured.

01

Domain expiry reminders

Report cards highlight remaining days with green, orange, and red states based on urgency.

02

DNS record checks

A, AAAA, CNAME, NS, MX, TXT, and DMARC records are grouped by type so results stay readable.

03

HTTPS and TLS

Check HTTPS responses and TLS handshakes, including services that do not run on port 443.

04

Backup and export

Use JSON for complete backup, migration, and restore, and export PDF reports when you need a readable copy.

WORKFLOW

From adding a domain to reading a report, only the necessary steps remain

After you choose a use case, Domain Health Inspector enables suitable checks for websites, APIs, mail domains, home servers, parked domains, and other common scenarios.

  1. Add a domain or URL

    Paste a domain, URL, or explicit service port directly.

  2. Choose a usage profile

    Use layered menus to select website, API, mail, or home-service scenarios.

  3. Review the health report

    Read results by registration, DNS, HTTP, TLS, and mail categories.

  4. Export and back up

    Preserve full app data with JSON backup and export readable PDF reports.
