Common troubleshooting notes

  • If a domain report is incomplete, run the inspection again after confirming the device has internet access.
  • RDAP and registrar data may be unavailable or inconsistent depending on registry and registrar responses.
  • HTTPS and TLS checks depend on the selected service port and public network reachability.
  • Mail security checks depend on DNS TXT, MX, SPF, DKIM, and DMARC records being publicly available.
  • Before clearing local data, export a JSON backup or PDF report if you need to keep a copy.
