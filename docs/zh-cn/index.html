功能

围绕真实域名用途组织检查项

DomainName 不只是给域名打分，而是清晰标识检查项是否正常、需要关注、已禁用或尚未配置。

01

域名到期提醒

报告卡片展示剩余天数，并根据紧急程度区分不同状态。

02

DNS 记录检查

A、AAAA、CNAME、NS、MX、TXT 和 DMARC 等记录按类型分组，结果更容易阅读。

03

HTTPS 和 TLS

检查 HTTPS 响应和 TLS 握手，也支持不运行在 443 端口的服务。

04

备份和导出

使用 JSON 做完整备份、迁移和恢复，需要可读副本时可以导出 PDF 报告。

流程

从添加域名到阅读报告，只保留必要步骤

选择用途后，DomainName 会为网站、API、邮件域名、家庭服务、停放域名等常见场景启用合适的检查项。

  1. 添加域名或 URL

    直接粘贴域名、URL 或明确的服务端口。

  2. 选择用途配置

    通过分层菜单选择网站、API、邮件或家庭服务等场景。

  3. 查看健康报告

    按注册信息、DNS、HTTP、TLS 和邮件分类阅读结果。

  4. 导出和备份

    使用 JSON 保存完整数据，并导出易读的 PDF 报告。
