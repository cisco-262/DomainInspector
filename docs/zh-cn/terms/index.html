本协议说明 DomainName 及其域名检查报告的使用规则。

1. App 使用

DomainName 是域名资产检查和报告工具。你需要对添加到 App 中的域名、端点和服务端口负责。

2. 不保证结果完整或准确

域名、DNS、RDAP、HTTPS、TLS 和邮件安全检查依赖公共网络、外部服务和第三方数据。结果可能不完整、延迟、不可用，或与其他工具解释不同。

3. 用户责任

  • 仅检查你拥有、运营或被授权检查的域名和端点。
  • 不要把导出的报告作为法律、财务、安全或运营决策的唯一依据。
  • 重要数据请自行保留备份。

4. 购买

如果 App 提供付费功能，购买将通过 Apple 内购处理。购买可用性、恢复购买、退款和账单遵循 Apple 政策及 App Store 基础设施。

5. 责任限制

DomainName 按现状提供。在法律允许的最大范围内，我们不对遗漏提醒、报告不准确、网络故障、域名过期、DNS 配置错误或导出文件处理导致的损失负责。

6. 联系

如对本协议有疑问，请联系支持。
