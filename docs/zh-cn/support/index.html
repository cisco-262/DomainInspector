支持

这里提供产品支持、常见问题排查和报告导出相关说明。

联系方式

DomainName 支持邮箱：support@opshome.run。

请提供 App 版本、iOS 版本、设备型号、受影响域名，以及你遇到的问题。不要发送密码、私钥或其他敏感凭据。

常见排查方向

  • 如果报告不完整，请确认设备可访问互联网后重新运行检查。
  • RDAP 和注册商数据可能因注册局或注册商响应差异而不可用或不一致。
  • HTTPS 和 TLS 检查依赖你选择的服务端口和公网可达性。
  • 邮件安全检查依赖公开 DNS 中的 TXT、MX、SPF、DKIM 和 DMARC 记录。
  • 清空本地数据前，如需保留副本，请先导出 JSON 备份或 PDF 报告。
