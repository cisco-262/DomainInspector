DomainName

支持

这里提供产品支持、排障方向，以及报告导出相关问题说明。

联系方式

如需 DomainName 支持，请发送邮件至 support@opshome.run。

请包含 App 版本、iOS 版本、设备型号、受影响的域名，以及你预期发生什么的简短说明。

常见排障说明

  • 如果域名报告不完整，请确认设备可以访问互联网后再次运行检查。
  • RDAP 和注册商数据可能因注册局或注册商响应不同而不可用或不一致。
  • HTTPS 和 TLS 检查取决于所选服务端口和公网可达性。
  • 邮件安全检查取决于 DNS TXT、MX、SPF、DKIM 和 DMARC 记录是否公开可用。
  • 清除本地数据前，如需保留副本，请先导出 JSON 备份或 PDF 报告。
