DomainName

隐私条款

DomainName 采用本地优先设计。域名清单、检查报告和备份文件由你自行控制。

1. 概述

DomainName 用于检查域名到期、RDAP 注册信息、DNS 记录、HTTPS 可达性、TLS 握手和邮件安全记录。

2. 本地保存的数据

App 可能在设备本地保存域名、服务端口、用途场景、检查设置、报告结果、报告历史、购买权益状态、语言偏好和本地备份相关数据。

3. 网络检查

当你运行检查时，App 会访问生成报告所需的公共 DNS、RDAP、HTTP、HTTPS、TLS 和邮件相关端点。这些检查由你主动触发，或由 App 对你管理的域名执行刷新。

4. 备份和导出

JSON 备份和 PDF 报告只会在你主动导出时生成。文件导出后由 iOS 文档分享流程处理，导出文件由你自行保管。

5. 我们不收集的数据

  • 本地使用不需要注册账号。
  • 不会将你的域名资产清单上传到 DomainName 云账号。
  • 不会要求你提供密码、DNS 服务商凭据、注册商凭据或私钥。
  • 不会收集抓包数据或浏览历史。

6. 支持

联系支持时，请只提供排查问题所需的信息。不要发送注册商密码、DNS 服务商凭据、私钥或其他敏感信息。
