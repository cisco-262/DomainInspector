Domain Checker: DNS & SSL

隐私条款

Domain Checker: DNS & SSL 采用本地优先设计。域名清单、检查报告和备份文件都由你自己控制。

1. 概览

Domain Checker: DNS & SSL 帮助用户检查域名到期、RDAP 注册数据、DNS 记录、HTTPS 可用性、TLS 握手和邮件安全记录。

2. 设备本地存储的数据

App 可能会在你的设备上保存域名、服务端口、使用场景、检查设置、报告发现、报告历史、购买权益状态、语言偏好和本地备份元数据。

3. 网络检查

当你运行检查时，App 会连接生成报告所需的公网 DNS、RDAP、HTTP、HTTPS、TLS 和邮件相关端点。这些检查由你主动发起，或由 App 针对你管理的域名刷新触发。

4. 备份与导出

JSON 备份和 PDF 报告只会在你选择导出时创建。导出文件由 iOS 文档分享处理，导出后的文件由你自行负责。

5. 我们不收集的数据

  • 本地使用不需要注册账号。
  • 不会把你的域名资产清单上传到 Domain Checker: DNS & SSL 云端账号。
  • 不会要求提供密码、DNS 服务商凭据、注册商凭据或私钥。
  • 不会收集抓包数据或浏览历史。

6. 网站访问统计

本网站使用 Yandex Metrica 进行基础网站访问统计，例如页面访问量、流量来源和交互统计。这些统计仅用于改进网站，与 Domain Checker: DNS & SSL App 在设备本地保存的数据相互独立。

7. 支持

联系支持时，请只提供排查问题所需的信息。不要发送注册商密码、DNS 服务商凭据、私钥或其他敏感信息。
